## Sobre o projeto

O **Easy Shopping Via Mobile** é uma landing page responsiva desenvolvida durante meus estudos no **DevClub**.

O projeto foi criado com o objetivo de praticar estruturação de páginas com HTML, estilização com CSS e adaptação do layout para diferentes tamanhos de tela.

## Tecnologias

* HTML5
* CSS3
* Google Fonts
* Media Queries

## O que pratiquei neste projeto

* Estruturação de páginas com HTML
* Estilização com CSS
* Organização de layouts
* Posicionamento de elementos
* Tipografia com Google Fonts
* Criação e estilização de botões
* Estados `hover` e `active`
* Responsividade
* Media Queries
* Adaptação do layout para dispositivos móveis

## Responsividade

O projeto possui um layout adaptável para diferentes tamanhos de tela.

Em dispositivos menores, os elementos são reorganizados para melhorar a experiência de navegação, o menu é simplificado e o conteúdo passa a ocupar melhor o espaço disponível.
